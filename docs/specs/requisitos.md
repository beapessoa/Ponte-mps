# Lista Completa de Requisitos

> **Movido.** Os requisitos funcionais e não funcionais (RF01–RF10, NF-USA/SEG/DES/CON/MAN) agora vivem em [`openspec/specs/`](../../openspec/specs/), um arquivo por capacidade (`usuarios`, `vagas`, `match`, `inscricoes`, `avaliacoes`, `rnf/<categoria>`), com prioridade, casos de uso relacionados e cenários de aceitação. A priorização ("20% mais importante") está em [`docs/01-visao.md`](../01-visao.md) §2.3.

> Esta versão (US01–US10, RNF01–RNF04) ficou desatualizada — por exemplo, só tinha 4 RNF em 3 categorias, enquanto `openspec/specs/rnf/` já tem 6 em 5 categorias — e foi mantida apenas no histórico do Git para referência.
